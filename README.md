# PC-Bridge (Electron)

[![Build](https://github.com/oleksander17072012-a11y/pcbridge-electron/actions/workflows/windows.yml/badge.svg?branch=master)](https://github.com/oleksander17072012-a11y/pcbridge-electron/actions/workflows/windows.yml)

Мост удалённого управления **своим собственным ПК**: тёмное окно-лаунчер, ключ
подключения, туннель и агент, который выполняет команды, снимает экран и управляет
окнами фоновым вводом. Переписан с Rust/Tauri на **Electron**.

Сборка — целиком в GitHub Actions: `windows-latest` прогоняет тесты, собирает
portable `.exe` и NSIS-установщик. Локально ничего компилировать не нужно.

## Что делает

```
чат / ассистент ──HTTPS──▶ trycloudflare.com ──▶ локальный релей 127.0.0.1:<порт>
                                                        │  Bearer <pairing key>
                                                        ▼
                                    ┌────────────────────────────────────────┐
                                    │ shell: cmd / PowerShell                │
                                    │ screenshot: GDI BitBlt → JPEG          │
                                    │ gui: PostMessage в фоновое окно        │
                                    │ windows: список / активация / закрытие │
                                    └────────────────────────────────────────┘
```

## Почему Electron и что это даёт

| | Tauri-версия | эта (Electron) |
|---|---|---|
| Размер | ~4 МБ | ~90 МБ (Chromium внутри) |
| Доступ к Win32 | нативный FFI на Rust | FFI через `koffi`: те же `user32`/`gdi32` |
| Прозрачность и скругления | WebView2 игнорировал прозрачность | `transparent: true` работает, углы рисует CSS |
| Перетаскивание окна | через регион и `HTCAPTION` | `HTCAPTION` через `koffi` + `-webkit-app-region` |
| Обновления зависимостей | Rust-крейты | `npm ci` по `package-lock.json` |

Практический вывод: Electron даёт предсказуемый рендер (скруглённые углы и
прозрачность работают как в браузере) ценой размера дистрибутива.

## Возможности

* `shell` — `cmd.exe /c` и `powershell -NoProfile -NonInteractive -Command`,
  таймаут с `taskkill /T`, денайлист на разрушительные команды.
* `screenshot` — GDI `BitBlt` + кодирование через `nativeImage.toJPEG`.
* `gui` — `moveTo`, `click`, `doubleClick`, `rightClick`, `typewrite`, `hotkey`,
  `press`, `scroll`, `dragTo`, `wait`. Сообщения шлются в окно под **виртуальным**
  курсором, физическая мышь и клавиатура не двигаются.
* `windows` — видимые окна с процессом и PID, активация и мягкое закрытие.
* Виртуальный курсор — отдельное прозрачное always-on-top окно, click-through.
* Журнал — рабочий лог: `stage` (этап), `step` (шаг), `result`, `error`, с глифами
  и временем; текущий этап виден в титлбаре. Дублируется в файл и в `GET /journal`.
* Чат рядом: кнопка «Копировать ключ + промпт» копирует блок и открывает Arena в
  правой половине экрана (браузер), лаунчер сжимается в левую. Есть вариант «Чат в
  окне» — отдельное окно приложения со своим persistent-профилем WebView2.
* Права администратора запрашиваются манифестом (`requireAdministrator`), трей,
  сворачивание в трей, запрос входа в аккаунт — в самом окне чата.

## HTTP API

Все эндпоинты, кроме `/health`, требуют `Authorization: Bearer <key>`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | `{"ok":true}` — проверка живости |
| GET | `/status` | состояние агента, хост, uptime, текущий этап |
| GET | `/windows` | кэш списка окон |
| GET | `/journal` | последние 100 записей журнала |
| GET | `/poll` | всегда `{"job":null}` (совместимость) |
| POST | `/note` | `{"text":"…","kind":"stage\|step\|result\|error\|note"}` |
| POST | `/cmd` | `shell` / `screenshot` / `gui` |
| POST | `/result` | no-op, оставлен для совместимости |

```bash
curl -s -X POST "$URL/cmd" -H "Authorization: Bearer $KEY" \
     -H 'content-type: application/json' \
     -d '{"command":"dir C:\\Users","shell":"cmd","timeout":60}'
```

Коды: `0` успех, `95` цель не принимает фоновый ввод, `124` таймаут,
`126` денайлист, `130` failsafe (курсор в левом верхнем углу), `400` некорректный запрос.

## Разработка

```bash
npm ci          # зависимости
npm test        # 19 юнит-тестов (node:test), работают и на Linux
npm start       # запуск приложения (только Windows: Win32 через koffi)
npm run dist    # portable + NSIS, требует Windows
```

Тесты покрывают то, что можно проверить без Windows: журнал и его структуру,
денайлист и таймауты команд, парсер URL туннеля, генерацию ключей и формат
pairing-блока, а также контракт UI: каждый `id` из `app.js` существует в разметке,
каждый IPC-канал из `preload` зарегистрирован в main, окно чата не получает preload.

## Где что лежит

```
%LOCALAPPDATA%\PC-Bridge\
├── pairing.key           блок PC-BRIDGE-PAIRING (URL туннеля + ключ)
├── pc_agent_log.txt      журнал всех действий
└── bin\cloudflared.exe   туннель, скачивается один раз (подпись проверяется)
```

## Безопасность

* Ключ = полный доступ к ПК. «Новый ключ» мгновенно отзывает старый.
* Приложение всегда запускается с правами администратора (манифест), поэтому
  команды с ключом выполняются уже повышенными правами.
* Окно чата не имеет доступа к мосту: у него нет preload и оно не упомянуто ни в
  одном IPC-канале, поэтому сайт не может вызвать команды приложения.
* `cloudflared` проверяется по Authenticode-подписи Cloudflare; неподтверждённый
  файл удаляется.
* `gui`-действия не трогают физические мышь и клавиатуру; failsafe — левый верхний угол.
* Денайлист — предохранитель, не песочница.

## Ограничения

* Только Windows x64.
* Фоновый ввод работает не везде: браузеры на canvas, игры, elevated-окна и UAC
  могут игнорировать `PostMessage` — возвращается код `95`, тихого отката нет.
* Quick tunnel меняет адрес при каждом перезапуске — копируйте новый блок ключа.
* Arena отдаётся за Cloudflare-челленджем, поэтому основной путь — «Чат в браузере».
